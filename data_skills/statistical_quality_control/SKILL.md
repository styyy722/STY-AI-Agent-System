# Statistical Quality Control

Use this skill when monitoring process stability, operational exceptions, quality metrics, or recurring KPI movement.

## Workflow

1. Define process metric:
   - Metric, unit, sample size, cadence, acceptable performance, and operational owner.

2. Choose chart:
   - X-bar/R, individuals/moving range, p-chart, c-chart, u-chart, or run chart depending on data type.

3. Calculate limits:
   - Centre line, upper control limit, lower control limit, rolling windows if justified.

4. Detect signals:
   - Points outside limits, runs, trends, shifts, cycles, special-cause variation.

5. Interpret:
   - Distinguish normal variation from actionable process changes.
   - Recommend investigation only for meaningful signals.

## Output Format

Return:
- Control chart design
- Signal rules
- Findings
- Business interpretation
- Recommended action
