# Customer Segmentation

Use this skill when grouping customers/users/accounts/products into actionable segments.

## Workflow

1. Define segmentation objective:
   - Retention, growth, pricing, service model, marketing, sales prioritization, product personalization.

2. Select features:
   - Recency, frequency, monetary value, tenure, product usage, margin, churn risk, channel, lifecycle, engagement.

3. Choose method:
   - Rule-based segmentation, RFM, quantiles, clustering, decision tree segmentation, lifecycle segmentation.

4. Validate:
   - Segment size, stability, separability, interpretability, business actionability, fairness/privacy constraints.

5. Recommend actions:
   - Offer, messaging, retention play, sales motion, service tier, pricing, product intervention.

## Output Format

Return:
- Segment definitions
- Feature table
- Segment profile
- Recommended actions
- Measurement plan
