# Causal Inference

Use this skill when stakeholders ask whether an action caused a change, not just whether metrics moved together.

## Workflow

1. Define causal question:
   - Treatment, outcome, population, timing, counterfactual, and decision.

2. Assess identification:
   - Randomization, natural experiment, pre/post design, treatment/control availability, confounders.

3. Choose method:
   - A/B test, difference-in-differences, matching, synthetic control, regression adjustment, uplift modelling.

4. Validate assumptions:
   - Parallel trends, overlap, no spillover, stable treatment, no measurement change, no major confounding event.

5. Interpret:
   - Effect size, uncertainty, limitations, external validity, and decision implication.

## Output Format

Return:
- Causal design
- Required data
- Assumptions
- Analysis method
- Caveats and recommendation
