# Metric Governance Review

Use this skill when a report, dashboard, board pack, semantic model, or analysis relies on metrics that need trust and consistency.

## Review Workflow

1. Define metric:
   - Name, business purpose, numerator, denominator, filters, exclusions, grain, time zone, and refresh cadence.

2. Check source alignment:
   - Source tables, transformations, semantic model measures, dashboard calculations, and reconciliation to system of record.

3. Check ownership:
   - Business owner, data owner, approval status, certified source, change process, and consumer teams.

4. Check quality:
   - Completeness, uniqueness, validity, freshness, referential integrity, distribution drift, and known caveats.

5. Check reporting risk:
   - Duplicate definitions, hidden filters, stale extracts, manual overrides, and inconsistent time windows.

## Output Format

Return:
- Metric trust rating
- Canonical definition
- Reconciliation checks
- Governance gaps
- Remediation plan
