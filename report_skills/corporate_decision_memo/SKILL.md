# Corporate Decision Memo

Use this skill when the user needs a decision-ready memo for a manager, CFO, executive committee, board, lender, or steering group.

## Memo Workflow

1. Frame the decision:
   - Decision required, deadline, owner, affected stakeholders, and consequence of inaction.

2. Summarise evidence:
   - Key facts, data points, finance implications, dashboard/report evidence, and confidence caveats.

3. Compare options:
   - Option, benefits, costs, risks, dependencies, timing, and reversibility.

4. Recommend:
   - Clear recommendation, rationale, quantified impact, assumptions, and risk mitigations.

5. Define execution:
   - Owner, next actions, approval required, implementation timeline, monitoring metrics.

## Output Format

Return:
- Decision required
- Recommendation
- Evidence summary
- Options table
- Risks and assumptions
- Approval and next steps
