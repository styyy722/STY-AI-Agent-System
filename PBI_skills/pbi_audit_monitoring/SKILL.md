# Power BI Audit and Monitoring

Use this skill for Power BI operational monitoring, adoption analysis, tenant audit reviews, and report estate rationalisation.

## Workflow

1. Define audit scope:
   - Tenant, workspace, app, semantic model, report, user group, or time period.

2. Review operational health:
   - Refresh failures, stale datasets, gateway failures, long refresh durations, ownership gaps.

3. Review adoption:
   - Active users, report views, unused reports, duplicate reports, high-value assets, low-use certified reports.

4. Review risk:
   - External sharing, broad workspace admin access, export activity, sensitivity label gaps, uncertified models used for executive reporting.

5. Recommend actions:
   - Retire, consolidate, certify, reassign owner, restrict sharing, fix refresh, or improve performance.

## Output Format

Return:
- Audit summary
- Findings table
- Risk rating
- Recommended actions
- Monitoring KPIs
