# Variance Bridge

Use this skill when explaining movements between actuals, budget, forecast, prior year, or prior period.

## Workflow

1. Define comparison:
   - Actual vs Budget, Actual vs Forecast, Actual vs Prior Year, Forecast vs Prior Forecast.

2. Quantify the total gap:
   - Absolute variance, percentage variance, favourable/unfavourable direction, and materiality threshold.

3. Decompose drivers:
   - Price/rate, volume, mix, FX, timing, one-off, operational driver, accounting reclass, scope change.

4. Write commentary:
   - Explain what changed, why it changed, whether it is recurring, who owns it, and what action is required.

5. Validate:
   - Bridge items must sum to total variance.
   - Avoid double counting drivers.

## Output Format

Return:
- Variance bridge table
- Driver definitions
- CFO-ready commentary
- Risks and follow-up actions
