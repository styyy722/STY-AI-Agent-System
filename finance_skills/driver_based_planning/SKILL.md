# Driver-Based Planning

Use this skill for FP&A planning models, budget builds, forecasts, and business cases where financial outcomes are derived from operational drivers.

## Workflow

1. Define the business model:
   - Revenue model, cost structure, operating units, planning horizon, scenario set, and reporting cadence.

2. Identify drivers:
   - Revenue: volume, price, conversion, retention, churn, usage, mix, pipeline.
   - Cost: headcount, salary, utilisation, capacity, vendor rates, unit costs, inflation.
   - Cash: payment terms, collections, inventory, capex, debt, tax.

3. Build driver formulas:
   - State formula, source, owner, assumption, and sensitivity.
   - Separate controllable and external drivers.

4. Validate:
   - Back-test drivers against actuals.
   - Compare plan to historical run rate.
   - Flag unrealistic productivity, margin, or growth assumptions.

## Output Format

Return:
- Driver tree
- Assumption table
- Forecast formulas
- Sensitivity levers
- Risks and validation checks
