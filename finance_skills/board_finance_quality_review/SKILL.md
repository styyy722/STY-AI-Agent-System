# Board Finance Quality Review

Use this skill before finance analysis is shared with executives, boards, lenders, investors, or senior stakeholders.

## Review Workflow

1. Validate numbers:
   - Recalculate key totals, ratios, variances, and percentages where data is provided.
   - Flag unsupported figures or missing source references.

2. Review assumptions:
   - Separate facts, management assumptions, model assumptions, and external assumptions.
   - Flag aggressive growth, margin, cost, cash, or discount-rate assumptions.

3. Review decision usefulness:
   - State the decision required.
   - Link analysis to financial impact, risk, owner, and timeline.

4. Review finance logic:
   - Check actual/budget/forecast periods, favourable/unfavourable signs, one-offs, recurring impacts, FX, price-volume-mix, and cash implications.

5. Recommend improvements:
   - Identify missing analyses, sensitivity checks, scenario cases, or supporting schedules.

## Output Format

Return:
- Board-readiness rating
- Critical calculation checks
- Assumption risks
- Missing evidence
- Recommended edits before release
