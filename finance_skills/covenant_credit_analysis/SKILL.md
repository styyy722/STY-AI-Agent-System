# Covenant and Credit Analysis

Use this skill for debt covenant testing, credit risk, lender reporting, refinancing support, and downside planning.

## Workflow

1. Identify debt structure:
   - Facility, maturity, interest rate, amortisation, security, covenants, reporting dates, cure rights.

2. Calculate metrics:
   - Net debt, EBITDA, leverage, interest cover, DSCR, fixed charge cover, liquidity, covenant headroom.

3. Normalize:
   - Adjust EBITDA for allowed add-backs only if documented.
   - Separate management adjustments from lender-approved adjustments.

4. Stress test:
   - Downside EBITDA, rate increases, working capital shocks, covenant breach timing, cash runway.

5. Recommend:
   - Action plan for breach risk, waiver, refinancing, debt paydown, cost action, equity injection.

## Output Format

Return:
- Covenant calculation table
- Headroom analysis
- Stress case
- Breach risk rating
- Recommended actions
